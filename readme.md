# ufo-catcher
こうようさい2026でロボコンブースで動かしたUFOキャッチャーのプログラム
KONDOサーボ3台とDual USBアダプターHSを使う
## 使い方
このレポジトリをcloneする
Dual USBアダプターHSをPCへ接続し、どのポートに刺さっているかを確認する。
main.pyの30行目くらいの`Servo = KondoServo("COM16")`をDual USBアダプターHSにポートに変える
`python3 main.py`でプログラムを起動
スペースキーで音声認識開始
マイクへ向かって「トリックオアトリート」と言う(認識精度の関係で実際に認識しているのはトリートだけ)
認識成功したらサーボが動くようになる

## 操作方法
矢印キー:前後左右
u,nキー:アーム上下
bキー:最初の画面に戻る
